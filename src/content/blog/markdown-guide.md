## 基本语法

### 标题

使用 `#` 到 `######` 表示六级标题。

### 强调

- **粗体**：`**粗体**`
- *斜体*：`*斜体*`
- ~~删除线~~：`~~删除线~~`

### 列表

1. 有序列表项 1
2. 有序列表项 2

- 无序列表项
- 无序列表项

### 代码

行内代码：`console.log('hello')`

代码块：
```javascript
function greet(name) {
  return `Hello, ${name}!`
}
```

### 图片

```markdown
![图片描述](/images/your-image.jpg)
```
